# VanBora — Marketplace de Transporte por Vans

Plataforma digital para conectar pessoas físicas, empresas e instituições que precisam contratar serviços de transporte a proprietários independentes e empresas de vans na Grande São Paulo.

## Estrutura do Projeto

- `frontend/`: Aplicação web React + Vite + TypeScript + Tailwind CSS (Mobile-First, UI amigável e acessível).
- `backend/`: API REST Java / Spring Boot.
- `docs/`: Especificações de produto, requisitos, regras de negócio e UX/UI.
